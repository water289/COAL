# Test Cases for Human Language Scripting Interpreter

## Test Case 1: Basic Arithmetic
```
add 10 and 20
subtract 5 from 15
multiply 6 and 7
divide 20 by 3
```

**Expected Output:**
```
30
10
42
Quotient: 6
Remainder: 2
```

---

## Test Case 2: Variable Storage and Display
```
store 100 in balance
show balance
store 50 in amount
show amount
add balance and amount
```

**Expected Output:**
```
balance = 100
amount = 50
150
```

## Test Case 10: Help Command
```

```

**Expected Output:**
```
Commands:
  print <text>          - Display text or variable
  output <expr>         - Display expression result
  add <expr> and <expr> - Add two values
  subtract <expr> from <expr>
  multiply <expr> and <expr>
  divide <expr> by <expr>
  store <expr> in <var> - Assign variable
  show <var>            - Display variable
  add 1 to <var>        - Increment variable
  clear                 - Clear screen
  help                  - Show this help
  exit / quit           - Exit interpreter
  # comment             - Line comment
```

## Integration Test Session

Complete interactive session demonstrating multiple features:

```
>>> # Calculator demo
>>> store 100 in total
>>> show total
total = 100
>>> subtract 25 from total
75
>>> store 75 in total
>>> add 1 to total
>>> show total
total = 76
>>> multiply total and 2
152
>>> # Test division
>>> divide 100 by 7
Quotient: 14
Remainder: 2
>>> print Thank you for using the interpreter
Thank you for using the interpreter
>>> exit
Goodbye!
```

---

## Notes

1. All commands are case-insensitive
2. Variable names are case-insensitive  
3. Comments (lines starting with #) are ignored
4. Empty lines are ignored
5. Whitespace is flexible
6. Variables auto-create on first `store`
7. Attempting to use undefined variables shows error
8. Division by zero is handled gracefully

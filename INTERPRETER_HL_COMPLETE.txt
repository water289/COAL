COMMANDS IMPLEMENTED:
======================

1. store <value> in <var>
   - Store a number in a variable
   - Example: store 5 in n

2. print <value>
   - Print a value to screen
   - Example: print 10

3. print <value> <N> times
   - Print value N times
   - Example: print hello 3 times

4. increment <var>
   - Add 1 to a variable
   - Example: increment n

5. increment <var> by <value>
   - Add value to a variable
   - Example: increment n by 5

6. decrement <var>
   - Subtract 1 from a variable
   - Example: decrement count

7. decrement <var> by <value>
   - Subtract value from a variable
   - Example: decrement count by 2

8. show <var>
   - Display variable value
   - Example: show n

9. clear
   - Clear all variables

10. help
    - Display help message

11. exit / quit
    - Exit the interpreter

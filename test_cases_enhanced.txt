## Quick Test Run

To test the interpreter:

```bash
D:\COAL\bin\interpreter_enhanced.exe

>>> help
(shows all commands)

>>> store 10 in x
>>> add 1 to x
>>> output x * 2
Result: 22

>>> subtract 1 from x

x = 10

>>> store hello in msg

hello

>>> script
SCRIPT> store 0 in n
SCRIPT> loop 3 times

SCRIPT> add 1 to n
SCRIPT> endloop
SCRIPT> (press Enter)
0
1
2

>>> exit

```
